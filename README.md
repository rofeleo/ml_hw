# Гипотезы

1) Присутствует дисбаланс классов (85% на 15%): PR-AUC будет хуже, чем ROC-AUC. (Подтвердилась)
2) Большинство количественных признаков имеет right-skewed distribution с большим количеством нулей, следовательно, логарифмирование (с предварительным сдвигом на 1) улучшит качество логистической регресии. (Подтвердилась)
3) Признак PageValues будет топ-1 по значимости признак (корреляция с целевым признаком: 0.49). (Подтвердилась)
4) Композиция Ridge ∘ Lasso покажет лучший RP-AUC чем Ridge (Не подтвердилась - L2 регуляризация справилась с не актуальными и корреллированными признаками, однако Ridge ∘ Lasso позволила оставить 23 из 60 самых важных признаков)
5) Из-за дисбаланса классов порог классификатора 0.5 окажется неоптимальным (Подтвердилась)
